# Suite PMO Antamina

Hub de herramientas para la PMO de Antamina:

- **Relevo·PMO** — vacaciones, ausencias y relevos (mapa anual, radar de anticipación, accesos y checklist de traspaso).
- **PMO Automa · Minutas** — generador de actas con seguimiento de acuerdos y compromisos.
- **Asistente PMO** — consulta el estado consolidado de los proyectos.

> **Nota:** esta versión pública (GitHub Pages) usa **datos de ejemplo** y el Asistente opera en **modo local** (sin IA en la nube).
> La versión con IA real (DeepSeek) requiere un servidor local que no se incluye aquí por seguridad (contiene credenciales privadas).
