# Suite PMO Antamina

Hub de herramientas para la PMO de Antamina (6 consultores, 6 portafolios de proyectos).

| Herramienta | Qué hace |
|---|---|
| **Relevo·PMO** | Vacaciones, ausencias y relevos: mapa anual, radar de anticipación, control de accesos y checklist de traspaso. |
| **PMO Automa · Minutas** | Actas con agenda, acuerdos y compromisos. Guardadas en base de datos y consultables como fuente histórica. |
| **Transcripciones** | Repositorio de transcripciones de reuniones, indexadas y buscables. Generan actas con IA. |
| **Asistente PMO** | Responde sobre el estado de los proyectos usando los datos y el texto de las transcripciones, citando sus fuentes. |

## Dos modos de uso

**1. Esta página (GitHub Pages) — demostración**
Funciona con datos de ejemplo guardados en el navegador. La búsqueda en el histórico
opera en local y el Asistente usa su motor de palabras clave.

**2. Con servidor local — versión completa**
Añade base de datos **SQLite** (actas, compromisos y transcripciones con búsqueda de
texto completo) y un **Asistente con IA** que recupera los fragmentos relevantes del
histórico antes de responder (RAG) y cita sus fuentes.

El servidor no se publica en este repositorio porque contiene credenciales privadas.
